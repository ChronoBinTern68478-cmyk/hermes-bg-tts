# Български TTS Плъгин за Hermes Agent (BgTTS-38M-V2)

Този проект предоставя локална интеграция на българския модел за синтез на реч **BgTTS-38M-V2** (създаден от `beleata74`), предназначен за използване с AI агенти (като **Hermes Agent**). 

Проектът включва готов плъгин, който позволява на агента да говори на български език с изключително естествено звучене.

## ✨ Характеристики
- **Работи изцяло на CPU:** Не изисква мощна видео карта (NVIDIA CUDA) – идеален за обикновени компютри или сървъри.
- **Клониране на глас (Zero-shot):** Може да имитира тембъра на глас от 3-10 секунди аудио.
- **Интелигентна транслитерация:** Автоматично превръща латинските букви и думи в кирилица, за да звучи речта правилно (например "Hermes" се чете "Хермес").
- **Бърз и лек:** Моделът е само от 38 милиона параметъра и генерира реч много бързо.
- **Лесна конфигурация:** Изключенията за произношение на съкращения (API, CPU и др.) се управляват лесно чрез файла `replacements.py`.

## 🛠️ Инсталация

### 1. Клонирайте хранилището
```bash
git clone https://github.com/ВАШИЯТ_ПРОФИЛ/hermes-bg-tts.git
cd hermes-bg-tts
```

### 2. Изтеглете модела
Тъй като моделът е голям (около 150 MB), той не се съдържа директно в това хранилище. Трябва да го изтеглите от Hugging Face:
```bash
pip install huggingface_hub
python -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='beleata74/BgTTS-38M-V2', local_dir='./BgTTS-38M-V2')"
```
*(Забележка: Уверете се, че файлът `checkpoint_inference.pt` в папката на модела е преименуван на `checkpoint.pt`, за да работи кодът правилно).*

### 3. Инсталирайте зависимостите
Силно препоръчително е да използвате виртуална среда (Python 3.12):
```bash
python -m venv venv
source venv/bin/activate  # За Linux/macOS
# venv\Scripts\activate   # За Windows

pip install -r requirements.txt
```

## 🚀 Употреба

### Тестване на двигателя (Standalone)
Можете да тествате генерирането на реч директно, без да стартирате Hermes:
```bash
python bg_tts.py
```
Това ще генерира файл `test_output.wav` в главната папка.

### Интеграция с Hermes Agent
За да използвате този плъгин с Hermes, поставете папката `hermes_plugin` в директорията с плъгини на вашия Hermes Agent (обикновено `~/.hermes/plugins/` според документацията на Hermes).

## ⚙️ Конфигурация
*   **Смяна на гласа:** По подразбиране се използва `./BgTTS-38M-V2/samples/sample_male_bg3.wav`. Можете да смените пътя до `.wav` файл (3-10 секунди чист глас), за да клонирате различен глас.
*   **Речник на изключенията:** Ако чуете, че дадена английска абревиатура (напр. API, CPU) се чете странно, просто отворете `replacements.py` и добавете правилото за нея.
